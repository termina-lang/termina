How it is measured

IndicatorRule
CodeLines with at least one non-blank character outside a comment. A line with code and a trailing comment is a code line.
CommentLines without code that contain comment text or lie inside a block comment. Documentation comments are comment lines.
BlankLines with only white space outside a comment.
UnitFunction, or method, procedure, viewer, action or case of a class. Its lines range from its documentation comment, if any, to its closing brace.
lslocIn a unit: 1 for the header, plus 1 for each declaration, assignment, expression statement, if, for, match, return, continue and reboot. In a module: the lsloc of its units, plus 1 for each import, global, constexpr, extern function, struct, struct field, enum, interface, interface procedure, class, class field, class port and instance.

NestingMaximum depth of nested if, for and match statements. An else if does not increase the depth.
ParametersNumber of parameters, excluding self.
CallsNumber of distinct units and operations called by the unit, from all the instances of its class.
